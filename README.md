# Hercules

Сайт школьного фитнес-клуба: регистрация учеников и учителей, профиль, расписание занятий
с датой, временем и местом, панель учителя для записи учеников на уроки.

Стек: PHP 8 + MySQL/MariaDB (mysqli), без фреймворков. Разрабатывается под XAMPP.

## Запуск локально (XAMPP)

1. Склонируй репозиторий в `xampp/htdocs/Hercules`.
2. Запусти Apache и MySQL в панели XAMPP.
3. Создай базу и таблицы:
   ```
   xampp/mysql/bin/mysql -u root < schema.sql
   ```
   или импортируй `schema.sql` через phpMyAdmin. Скрипт создаёт базу `hercules`
   и заполняет справочник уроков.
4. Скопируй `config.example.php` в `config.php` и задай `TEACHER_INVITE_CODE`.
   Без кода регистрация учителей закрыта.
5. Открой http://localhost/Hercules/main.php

Подключение к БД настраивается в `db.php` (по умолчанию `root` без пароля, как в XAMPP).

## Роли

- **Ученик** регистрируется на `registration.html`, входит на `login.html`.
- **Учитель** регистрируется на `teacherreg.html` только с кодом приглашения из `config.php`,
  входит на `teacherlogin.html`, записывает учеников на уроки в `teacher.php`.

## Миграции

`schema.sql` уже содержит актуальную структуру. Файлы в `migrations/` нужны только
для обновления старых баз, созданных до этих изменений.

## Безопасность

- Пароли хранятся через `password_hash`, все запросы к БД подготовленные.
- Формы, меняющие данные после входа (смена пароля, создание записи в расписании),
  защищены CSRF-токеном (`csrf.php`).
- `config.php` и дампы базы с данными учеников не попадают в git (`.gitignore`).
